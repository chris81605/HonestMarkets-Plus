# HonestMarkets 誠信小販

## 說明

探索市集可以直接買到需要的商品，告別一杯茶一包菸，探索市集探一天的煩惱。

本模組最初由 **FungiEggroll** 製作，提供在市集中直接購買商品的功能。

自 **v0.2.0** 起，在原模組基礎上進行大規模重構與擴充。保留「探索市集、直接購買商品」的核心玩法與部分原版文案，並將原本以固定商品為主的市場逐步發展為會依遊戲資料、市場行情、玩家能力與時間變化的**動態市場系統**。

## 重構版特色

重構版並不只是增加更多可購買商品，而是盡可能將原本固定的商品、供貨、價格、種子與偷摸機制改為動態生成。

只要官方或其他 Mod 沿用 DoL 既有的資料結構，許多新增內容便能自動被 HonestMarkets 辨識，而不需要另外建立固定商品清單。

### 動態商品市場

一般商品直接讀取遊戲目前存在的 `setup.foodstuff`，並依商品分類建立市場。

每次探索市集時：

- 各分類會隨機出現部分商品。
- 商品會生成不同的供貨數量與市場行情。
- 同一次探索期間，商品、庫存與報價保持固定。
- 返回市場介面不會免費重新刷新商品。
- 可以花費時間繼續探索，重新尋找一批商品。

因此官方或其他 Mod 新增符合既有資料格式的商品時，通常也能自動進入市場。

### 動態供貨與批發價格

商品會以不同規模的批次出現：

- 零散
- 小批
- 中批
- 大批
- 清倉

商品價值會影響供貨規模：高價商品通常偏向小批供貨，便宜商品則較容易形成大批或清倉。

批次越大，通常越有機會取得較低的單位成本，因此市場除了購買自己需要的商品，也可以作為大量進貨後再擺攤出售的來源。

每批商品的行情在生成時即會鎖定，部分購買只會減少剩餘庫存，不會重新抽取價格。

### 市場行情

商品會依目前進貨成本與正常擺攤價值顯示簡單的行情提示：

- `【不太划算】`
- `【尚可】`
- `【有利可圖】`

這些提示可以快速判斷目前批次是否適合拿來轉售。

開啟 Debug 後，則可以查看更詳細的批次、價格、成本與預估收益資料。

### 動態種子市場

種子不再使用固定植物清單，而是自動尋找目前遊戲中可以取得種子的植物。

市場會：

- 排除玩家已經知道的種子。
- 每個五日週期隨機提供 0～3 種未知種子。
- 同一週期內不會因重新進入市場而刷新。
- 購買後立即解鎖對應植物，且本週期不會重新補貨。
- 依植物本身的價值動態計算種子價格。

因此其他 Mod 新增符合 DoL 既有種植資料結構的植物時，也能自動參與種子市場。

### 動態偷摸系統

原版 HonestMarkets 的市集偷摸玩法仍然保留，但已重新設計並與 DoL 原生詭術系統連動。

市場會依目前的商品價格分布與玩家詭術，決定哪些商品屬於玩家目前有能力嘗試的目標。

商品越昂貴、一次想摸走的數量越多，通常就越困難；接近收攤時，攤販警戒下降，也會影響下手難度。

偷摸分成兩個階段：

1. 先花時間觀察，隨機找到一個可以嘗試的商品與數量。
2. 顯示 DoL 原生詭術難度後，由玩家決定是否真的下手。

成功與失敗仍由 DoL 原生 `<<skulduggerycheck>>` 判定。

如果偷摸失敗，則還會依這次行動相對於玩家詭術能力的風險判斷是否被發現。越接近自己的能力極限，被抓的風險通常越高。

被抓後會遭攤販趕出市場，當天無法再次與 HonestMarkets 交易。

### 市場時間與探索狀態

HonestMarkets 具有自己的市場探索與營業狀態。

市場正常營業時間為 **07:00～20:59**，21:00 起開始收攤並停止交易。

市場中的行動也會實際消耗遊戲時間，例如：

- 一般購買：`(00:05)`
- 觀察偷摸目標：`(00:05)`
- 實際下手：`(00:05)`
- 探索更多商品：`(00:30)`

接近收攤時，部分耗時過長的行動會無法繼續進行。

### 相容性

需搭配 **Maplebirch 框架** 使用。

重構版盡可能避免使用固定商品白名單，而是利用 DoL 本身的資料，例如：

```js
setup.foodstuff
shop.sell_price
category
tending.has_seeds
```

因此只要新增內容沿用相容的資料結構，HonestMarkets 就能盡可能自動處理：

- 商品分類與市場供貨
- 批次數量與市場價格
- 擺攤轉售行情
- 偷摸商品與難度
- 可種植植物與種子市場

> **原版 HonestMarkets 提供了「在市集中直接購買商品」的核心玩法；重構版則在保留這個核心的前提下，將市集翻新為會依遊戲內容、商品價格、玩家能力與時間動態變化的市場系統。**

## 重構版更新紀錄

### v0.5.5 — 偷摸 Debug 資訊補強

- Debug 提示新增目前庫存、能力公式的理論最大偷摸數量，以及套用庫存限制後的實際上限。
- 原「偷摸數量」改標示為「本次偷摸數量」，方便辨識 1～上限之間的隨機結果。
- 修正偷摸數量公式註解，使其與目前 12 個硬上限一致。

### v0.5.4 — 偷摸數量上限調整

- 調整偷摸單次可選數量硬上限：由 6 個提高至 12 個。
- 商品價格與詭術能力仍會先決定實際可偷數量；12 僅作為最終防爆上限。
- 偷取數量越多仍會提高偷摸難度，整批商品價值亦會交由新版 `petty` 犯罪系統計算犯罪紀錄。

### v0.5.3 — 新版犯罪統計相容

- 市場偷摸正式接入 DoL 0.5.12.x 的分類犯罪系統，使用官方 `crimeUp` 並記錄為 `petty`。
- 犯罪值改為依本次企圖偷取商品的實際總價計算，不再固定記錄為 1。
- 犯罪紀錄改在玩家正式「下手」時產生，因此成功、失敗或被抓都只會記錄同一次偷摸行為。
- 犯罪值交由官方 `crimeUp` 處理潛行、詭術減免，以及 Current、History、Daily、Count 等犯罪統計。

### v0.5.2 — 全局商品價格與設定介面

- 偷摸價格難度改為依目前商品價格分布的相對分位動態計算，不再使用固定 £0.50 作為難度基準；全局價格倍率或其他整體價格尺度變化不再額外放大偷摸難度。

- 全局商品價格倍率調整為 **1×～50×**，預設為 **1×**，建議使用 **5～20×**。
- 全局商品價格倍率會套用至所有存檔，並同步影響商店購買、商品出售、HonestMarkets 與其他相關系統。
- 修改全局商品價格倍率後會立即生效，不需要重新載入遊戲。
- 使用預設 **1×** 時不保留額外的全局設定；從其他倍率恢復至 1× 時會自動清除設定紀錄。
- 微調模組設定介面，加入設定項目分隔、數值顯示、全局設定標籤與窄螢幕自適應。
- 模組設定標題改為「誠信小販+」，並整理玩家可見的設定說明。

### v0.5.1 — 全局商品價格倍率

- 新增全局商品價格倍率，用於調整遊戲整體商品經濟的價格尺度。
- 倍率為全局設定，會套用至所有存檔。
- 修改倍率後立即生效，不需要重新載入遊戲。
- 商品價格始終以原始價格重新計算，避免切換倍率時重複乘算。
- 設為 **1×** 可恢復原始商品價格。

### v0.5.0 — 模組設定

- 新增「誠信小販+」模組設定，需搭配 **Maplebirch 框架** 使用。
- 新增每個商品分類的最低與最高商品種類數設定，可在 **5～20** 間調整，預設為 **6～8**。
- 新增市場最大批次數量設定，可在 **50～2500** 間調整，預設為 **240**。
- 市場最大批次提供滑塊及 ±1／±10 微調。
- 新增恢復預設功能。
- 市場供應設定會在建立新市場時鎖定，因此修改設定不會影響目前已生成的商品、庫存與行情。

### v0.4.9 — 維護註解整理

- 整理並擴充核心市場系統的維護註解，不改變既有市場、偷摸與價格平衡。
- 補充批次供貨、價格權重、批發報價、部分購買與市場行情的計算說明。
- 將偷摸流程整理為「候選商品 → 詭術檢定 → 失敗後被抓」三個階段。
- 補充價格分布、偷摸數量、時段難度、能力負荷與隨機判定等說明。
- 補充種子價格與遊戲貨幣單位相關說明。

### v0.4.8 — 偷摸被抓風險

- 偷摸失敗後的被抓風險改為依本次難度相對玩家詭術的「能力負荷」計算，不再使用固定 25%。
- 能力負荷越高，失敗後被發現的風險越高。
- 新增現場隨機波動，使相同難度的偷摸不會永遠具有完全相同的被抓風險。
- 被抓風險會在找到偷摸目標時鎖定，重新顯示確認頁不會重新抽取。
- Debug 新增能力負荷、基礎被抓率、現場波動與最終被抓率。

### v0.4.7 — 偷摸被抓判定調整

- 偷摸失敗後的被抓機率暫時調整為固定 25%，避免難度在成功檢定與被抓判定中被重複放大。
- 被抓隨機判定改用 HonestMarkets 共用隨機函式。
- 補充偷摸價格分布、數量、時段與難度相關的維護註解。

### v0.4.6 — 兩階段偷摸

- 偷摸流程拆分為兩個階段：先花 5 分鐘觀察目標，再決定是否下手。
- 觀察後會顯示 DoL 原生詭術難度；只有真正下手才會再花 5 分鐘並執行詭術檢定。
- 玩家可以在看到目標與難度後放棄，此時只消耗觀察時間。
- 若觀察後市場已經收攤，原本找到的機會會失效。
- 市場中的耗時操作統一使用原版 `(HH:MM)` 格式顯示時間成本。

### v0.4.5 — 行動時間與市場封鎖

- 一般商品、種子與肥料購買新增實際時間成本。
- 完整偷摸嘗試消耗 10 分鐘。
- 偷摸失敗後新增「是否被當場抓到」的判定。
- 被抓後當天會被 HonestMarkets 拒絕交易，隔日自動解除。
- 市場入口與各子場景新增當日封鎖狀態。
- 行動以開始時是否仍在營業為準，已經開始的有效行動可以正常完成。

### v0.4.4 — 市場營業時間

- 市場正常營業時間統一為 **07:00～20:59**。
- 21:00～21:59 為收攤中，22:00～05:59 已打烊，06:00～06:59 為開市準備。
- 接近收攤時會降低偷摸難度，並加入一定程度的隨機波動。
- 時段只影響偷摸難度，不會讓玩家越級嘗試原本超出能力的高價商品。
- 接近收攤時會限制無法在營業時間內完成的探索行動。
- 購買與偷摸執行層新增營業時間防護。

### v0.4.3 — 動態偷摸價格分布

- 偷摸商品的能力門檻改為依目前 `setup.foodstuff` 的實際價格分布動態建立。
- 玩家詭術越高，可以嘗試的商品價格範圍越廣。
- 官方或其他 Mod 新增、移除商品或修改價格後，新的市場探索會自動重新建立價格分布。
- 價格分布只保存在 runtime，不寫入存檔。
- Debug 新增目前偷摸價格範圍相關資訊。

### v0.4.2 — 詭術與時段偷摸判定

- 商品通過能力門檻後，再依價格與能力餘裕決定一次可能摸走的數量。
- 偷摸難度改為依商品價值與數量動態計算，不再固定為 500。
- 新增市集時段對偷摸難度的影響。
- 時段只影響成功難度，不改變玩家能夠嘗試的商品價格範圍。
- Debug 可查看商品價值、數量、時段修正與最終難度。
